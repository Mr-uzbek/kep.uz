# kep.uz solutions

My Python solutions to problems from [kep.uz](https://kep.uz), an Uzbek competitive programming platform.

Each file is named `<problem number>.<problem name>.py`.

| # | Problem | File |
|---|---|---|
| 1 | Sum of two numbers | [1.IkkiSonYig'indi.py](1.IkkiSonYig'indi.py) |
| 2 | The larger of two numbers | [2.IkkiSondanKattasi.py](2.IkkiSondanKattasi.py) |
| 10 | Number and digit | [10.SonVaRaqam.py](10.SonVaRaqam.py) |
| 16 | Factorial | [16.Factorial.py](16.Factorial.py) |
| 22 | Divisibility check | [22.Bo'linishniTekshirish.py](22.Bo'linishniTekshirish.py) |
| 23 | First digit of a number | [23.SonniBrinichiRaqami.py](23.SonniBrinichiRaqami.py) |
| – | Statistics of elements | [statistikaElementlari.py](statistikaElementlari.py) |

## Run

```bash
python3 "16.Factorial.py"
```

Input is read from standard input, as on kep.uz.
